# Classificacao com modelos semi-supervisionados

Projeto de estudo sobre aprendizado semi-supervisionado, com notebooks de aula e atividades praticas.

## Estrutura

- `Aulas/`: notebook da aula sobre aprendizado semi-supervisionado.
- `Atividades/`: notebooks de pratica, incluindo uma versao com solucao.
- `Dados/`: conjuntos de dados usados nos notebooks.

## Ambiente

Instale as dependencias com:

```bash
pip install -r requirements.txt
```

Abra os notebooks em `Aulas/` ou `Atividades/` em um ambiente Jupyter.
